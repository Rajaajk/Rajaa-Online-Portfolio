Approach

How I Build Products for Real People

Constraints aren't limitations — they're innovation catalysts. In markets where every tap costs data and every second matters, simplicity isn't optional.

Start with Access

If users can't reach it, it doesn't exist. Every product begins with the question: how do we get this into their hands with zero friction?

Design for Friction

Every interaction costs data, time, and trust. Make every tap count. Strip away everything that doesn't serve the user's core need.

Measure Behavior

In low-trust markets, actions speak louder than surveys. Watch what users do, not what they say. Let data drive every iteration.

OzGPT — Multilingual AI for Feature Phones

Pakistan's first telco AI assistant across 6 channels and 5 languages. Built for the 60% of users who don't have smartphones.

My Role

  • Multi-channel accessibility (USSD, SMS, IVR, Web, App, MZA)
  • Curated multilingual datasets for Urdu, Punjabi, Sindhi, Pashto, English
  • Telco billing & CRM integration coordination
  • Daily reporting across 6 live channel dashboards
  • Voice-first UX design for zero-literacy users

Key Decisions

  • USSD first (*6131#): Launched before Play Store — 62K peak daily users
  • Regional fine-tuning: LLM adapted for local dialects, not just translation
  • IVR → SMS fallback: Zero query drop-off architecture
  • Data pack bundles: Integrated with Zong daily/weekly plans
  • 6-channel distribution: Web + App + USSD + IVR + SMS + MZA

Global Relevance

Multilingual, low-bandwidth AI distribution reaches 2.8B+ non-English speakers. The 6-channel architecture is directly replicable in MENA, Africa, and LATAM — proving AI doesn't require a smartphone.

Cloud Storage · Jazz · 2024

Portall — Solving Storage Anxiety

Cloud storage for budget device users with limited memory and inconsistent connectivity. Infrastructure migrating from S3 to MinIO for scale — with DCB billing fully live.

3Platforms
iOS · Android · Web
MinIOInfra
Migration
DCBBilling
Integrated

My Role

  • Sync architecture design for intermittent 3G connectivity
  • Lightweight upload flow for low-end handsets
  • Cross-platform release coordination (iOS, Android, Web)
  • DCB payment process scoping and implementation
  • MinIO bucket migration coordination for storage scale

Key Decisions

  • Offline-first sync: Queue locally, push when connected — no data loss
  • Smart compression: Auto-optimize media size before upload
  • Device health prompts: Proactive nudge when storage drops below 15%
  • Bundled pricing: Integrated with Jazz data packs for zero-friction upsell
  • DB separation: App DB decoupled from infra for resilience

Global Relevance

Storage anxiety affects 1B+ budget smartphone users. Offline-first sync and data-cost awareness are essential for cloud products in Africa, South Asia, and LATAM. The MinIO migration shows infrastructure-level PM ownership.
